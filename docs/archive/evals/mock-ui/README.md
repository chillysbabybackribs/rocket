# Rocket eval mock UI

Braintrust-style **local** panel for Rocket eval artifacts. Component parity with [Braintrust Experiments](https://www.braintrust.dev/app/rocketv1/p/My%20Project/experiments):

| Braintrust | Mock |
|------------|------|
| Left nav (Experiments, Datasets, Playgrounds, …) | Same groupings (Evaluate / Monitor) |
| Experiments list + layout chips | List, Grid, Summary, Summary table |
| Compare selected experiments | Row checkboxes + Compare |
| Dataset rows (Input, Expected, Tags) | `sample-data.json` + JSONL-shaped rows |
| + Experiment | Hint → `eval:matrix:run` |

**Data**

- `sample-data.json` — demo matrix + harness runs
- `live-data.json` — generated by `npm run eval:mock-ui:sync` from `.artifacts/evals/*/summary.json`
- **Load JSON** — import any export shaped like `sample-data.json`

**Run**

- **In Rocket:** rail **flask** icon (side panel, same column as the browser).
- **Browser only:** `npm run eval:mock-ui:sync` then `npm run eval:mock-ui` → http://127.0.0.1:8765/

Link to production Braintrust is in the mock sidebar footer.
