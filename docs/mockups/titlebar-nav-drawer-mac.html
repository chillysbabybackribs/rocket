Section drawer in the toolbar

One icon (Sections) sits after the traffic lights. Clicking it slides the section names out to the right, pushing the title along. Each section can be kept in the toolbar for good, consolidated into the drawer, renamed or reordered, from the Customize popover at the end of the drawer or by right-clicking the icon. When Goals is in the closed drawer, its count rides on the icon.

E · Right-click on the iconThe Mac toolbar's own route to customizing, plus a quick switch for every section.

  • Kept sections live outside the drawer, right of the icon, in their own glass group. Consolidated ones only show when the drawer is open. If every section is kept, the icon still opens Customize.
  • Renaming only changes the label. The app map, the agent tools and screen-reader names keep the real section names, so a model asked to open "evals" still finds it.
  • The drawer stays open until toggled, so a section you use often doesn't need two clicks each time; it closes with Esc when focus is in it. The choice (open or closed, kept, names, order) is saved per window.
  • Motion: the drawer's width and each name ease in with Apple's spring-like curve, names staggered 30ms apart; the grid icon turns a quarter as it opens.
